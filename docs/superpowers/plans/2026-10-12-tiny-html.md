# tiny-html Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build tiny-html — ultra-simple static HTML learning playground with live preview and rule-based assistant, deployable to GitHub Pages with zero build.

**Architecture:** Modular static, no build. `tiny/` framework (custom tags + game JS + CSS) loaded via plain script tags. `app/` playground (editor, iframe preview, assistant, lessons). All client-side, localStorage only.

**Tech Stack:** HTML5, CSS3, Vanilla JS (ES6, no modules bundler — plain `<script>`), sandboxed iframe srcdoc for preview, GitHub Pages static hosting.

## Global Constraints

- Static only — no backend, no npm build, no API keys — must run by opening index.html.
- Ultra-simple learner API — max 7 custom tags + max 15 tiny.* functions.
- Live preview under 500ms after keystroke via 300ms debounce + iframe srcdoc.
- Assistant is rule-based regex, never blocks preview, friendly hints.
- Every file must work from file:// and https:// (GitHub Pages) with relative paths.
- Progress in localStorage key `tiny-html-*` only.
